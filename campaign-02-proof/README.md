# Campaign 2 Proof

Tutorial completed: [Store Data on Cell](https://docs.nervos.org/docs/dapp/store-data-on-cell)

This repo uses a distinct **cell journal** proof flow for Campaign 2. The tutorial stores one journal-style sentence in a CKB output cell, waits for the transaction to commit, then reopens the live cell by out point and decodes the stored text.

## Rerun

Start OffCKB devnet first:

```bash
offckb node
```

Then run:

```bash
cd ckb-store-cell-journal
npm install
npm run campaign02:cell-journal
```

The signing key lives in the ignored `.env` file generated by OffCKB and is not committed.

## Explorer Note

This is local OffCKB devnet proof. The transaction hash is real on the local chain but is not expected to appear on public CKB explorers.
